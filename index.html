BookScanner Web 実現性チェック

このページを iPhone / Android の Safari・Chrome で開くと、Web 版スキャナーが実際に使える「素材」が分かります。サーバーには何も送信しません。

  1. 「背面カメラを起動」を押し、本を 20〜40 cm の距離で映す（レンズが勝手に切り替わってプレビューが跳ばないかも見る）
  2. 「このフレームを無音で取得」で、動画フレームから静止画が取れることを確認する
  3. 「処理負荷を測る」で、ブラウザ内の画像処理がどれくらい回るかを見る
  4. ホーム画面に追加した状態（PWA）でも同じ結果になるか確かめる
